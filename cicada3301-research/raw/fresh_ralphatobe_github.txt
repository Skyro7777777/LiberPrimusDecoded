Repository for decoding the remaining Liber Primus pages.

Unsolved Liber Primus pages

Liber Primus cipher (Gematria Primus)

Packages:

OpenCV

numpy

scipy

matplotlib

Running the repo:

Download the unsolved Liber Primus pages

Unzip vocabulary.zip

Run 
python process_characters.py
 to uniformly crop vocabulary images

Run 
python process_images.py
 to extract transcripts from Liber Primus pages
